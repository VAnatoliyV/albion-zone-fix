# Albion Journal для Windows — спецификация и план

Дата: 2026-10-08. Дизайн одобрен пользователем в чате тремя частями; письменную
спецификацию и план пользователь велел не ждать («делай приложение уже»).

## Цель

Одна программа для Windows 11 (Европа), выросшая из Albion Zone Fix, со всем,
что есть в Albion Journal для мака: сбор цен (свои цены + отправка в ADP),
счётчик фейма/серебра/урона, слежка за зоной и карта Авалона, карточка зоны по
кнопке мыши 4 (OCR Windows), Zone Fix (переходы, проверка серверов,
трассировка, обход), автообновление, поддержка в Discord.

## Устройство

- Один `AlbionJournal.exe` (Go, windows/amd64, без CGO) + `acp-prices.exe`
  (приёмник своих цен, тот же Go-код, что у мака) + `zapret/` (как у Zone Fix).
  Без установщика: zip, распаковал и запустил. Права администратора
  (WinDivert) — UAC при запуске, как у Zone Fix сейчас.
- **Пакеты:** WinDivert (internal/sniff Zone Fix) ловит UDP Albion; каждый
  пакет идёт и в учёт переходов Zone Fix, и в разборщик форка сборщика
  (`~/Developer/albion-fame/albiondata-client`, подключён как модуль через
  replace; в форк добавляется вход «сырой IP-пакет» без pcap).
- Сбор цен и счётчик — переключатели внутри одного процесса.
- Данные: `%AppData%\Albion Journal\` (журнал, сессия, свои цены, файл места,
  настройки).
- **Окно:** нативное окно Windows с WebView2 (есть в Windows 11), страница
  зашита в exe, данные отдаются на 127.0.0.1. Иконка в трее (показать,
  запустить/остановить сбор, выход); крестик прячет в трей.
- **Вкладки:** Мои цены, Общие, Сессия, Зона, Переходы (Zone Fix). Сверху
  строки состояния: Приёмник, Сбор цен, Сайт, Счётчик фейма. Оформление как
  у мак-версии (тёмная, пиксельная, кролик). Языки: ru, en, es.
- **Настройки:** язык; отправлять цены в ADP (по умолч. да); запуск с
  Windows; начинать сбор при открытии; останавливать всё при выходе;
  отправлять связи на карту; автообновление; кнопка карточки зоны;
  поддержка (Discord https://discord.gg/5pV9ZqZMve + «скопировать сведения»
  без игровых данных — тот же фильтр, что у мака).
- **Карта Авалона:** как на маке — текущая зона из пакетов, отчёты
  tooltip/pass на `https://129-80-180-213.sslip.io/roads/report` (JSON,
  поле server="europe"), окно карты — второе окно WebView2 с
  `https://vanatoliyv.github.io/albion-craft-profit/#map/here=<код>`.
- **Карточка зоны:** хук мыши (WH_MOUSE_LL, XBUTTON1), снимок области у
  курсора (GDI), OCR Windows.Media.Ocr через PowerShell, разбор тултипа и
  нечёткое опознание — порт `app/Зона.swift` на Go с теми же проверками на
  настоящих строках. Показ во вкладке и уведомлением Windows; панели поверх
  игры нет (запрет SBI). Нужен языковой пакет OCR — программа проверяет и
  подсказывает.
- **Автообновление:** GitHub releases этого репозитория; zip подписан нашим
  ed25519-ключом (приватный только у пользователя на маке), открытый ключ
  вшит; без совпадения подписи не ставится. Установка — при выходе, через
  отдельный маленький процесс, который ждёт выхода и подменяет файлы.

## Проверка

Всё, что не зависит от Windows, — тесты Go на маке (`go test ./...`), плюс
`GOOS=windows GOARCH=amd64 go build` и `go vet` под Windows. Всё, что зависит
(WinDivert, WebView2, трей, хук мыши, OCR, уведомления), — тестер на Windows 11
по чек-листу этапа, присылает журнал.

## Предупреждение о чёрном экране (решение пользователя 8 октября 2026)

1. **В момент перехода:** если новый игровой сервер не ответил на CONNECT
   за ~2 с (настраиваемо), сразу уведомление Windows «Сервер зоны не
   отвечает — похоже на чёрный экран» (учёт переходов Zone Fix уже это
   распознаёт). Не чаще одного уведомления на переход.
2. **Заранее по истории:** карточка зоны (кнопка мыши 4 на портале)
   показывает риск по прошлым переходам этого человека в эту зону:
   «чёрный экран был в N из M переходов». Это вероятность, не гарантия;
   при M < 3 не показывать.
Входит в этап 4 (вместе с карточкой зоны).

## Россия и zapret (обсуждено с пользователем)

Иконки предметов — с копии на GitHub Pages (render заблокирован в РФ);
встроенный обход по умолчанию выключен (свой zapret у человека); Telegram не
добавлять; недоступность сервера карты/ADP — честное сообщение.

**Этап 1 — окно, сбор цен, счётчик, Zone Fix:**
- T1. Форк: вход «сырой пакет» (`client.FeedRaw(ipPacket []byte)` или
  аналог), режим без pcap; конфиг из кода (ADP вкл/выкл, сессия вкл/выкл,
  каталог данных); тест на записанных пакетах.
- T2. Zone Fix → Albion Journal: модуль форка через replace, раздача пакетов
  в обе стороны, каталог данных `%AppData%\Albion Journal`, переименование
  программы/зипа в AlbionJournal; тесты.
- T3. Окно WebView2 + трей + страница с вкладками (Мои цены, Общие, Сессия,
  Переходы; Зона — заглушка), строки состояния, настройки этапа 1, языки
  ru/en/es.
- T4. Приёмник `acp-prices.exe`: сборка под Windows, запуск/остановка из
  программы, кнопка «Открыть сайт»; `собрать.sh` кладёт всё в zip.
**Этап 2 — автообновление и поддержка** (передвинуто вперёд по решению
пользователя 8 октября 2026, чтобы тестер не ставил каждую сборку руками).
**Этап 3 — зона и карта.** **Этап 4 — карточка зоны (OCR) и
предупреждение о чёрном экране.**
