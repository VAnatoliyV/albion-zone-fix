# Albion Zone Fix — дизайн

Дата: 2026-10-05. Статус: согласован с пользователем в чате.

## Задача

У игроков Albion Online из России при переходе между локациями висит чёрный
экран или игра вылетает. Причина, по всем признакам, сетевая: при переходе
клиент подключается к другому игровому серверу по UDP (Photon, порты 5055/5056),
и фильтр провайдера теряет или режет эти пакеты.

Нужна программа под Windows, которая:
1. обходит фильтр провайдера для трафика Albion (движок zapret);
2. ведёт статистику переходов: какие локации грузятся долго или выкидывают,
   и как это меняется с обходом и без.

Для кого: пользователь и знакомые (вариант «для себя»). Установщика, подписи,
автозапуска нет.

## Ограничения

- Собираем на macOS: Go с кросс-компиляцией под windows/amd64, без CGO.
- Проверять работу можно только у тестера с Windows в России. Всё, что можно,
  проверяем здесь тестами на записанных пакетах.
- Программа запускается от администратора (WinDivert требует).
- Файлы игры не трогаем, в память игры не лезем.

## Состав поставки

Папка `AlbionZoneFix/`:
- `AlbionZoneFix.exe` — наша программа;
- `WinDivert.dll`, `WinDivert64.sys` — драйвер перехвата (из релиза WinDivert
  2.2, LGPLv3), его использует и наша программа, и winws;
- `winws.exe` (+ его файлы) — движок zapret из официального релиза
  bol-van/zapret или Flowseal/zapret-discord-youtube;
- `zones.json` — справочник зон (код → название ru/en), из нашего
  `зоны-дорог.json` / дампов;
- `ЛИЦЕНЗИИ.txt`.

## Компоненты

### 1. Наблюдатель (internal/sniff)

Открывает WinDivert с флагом `WINDIVERT_FLAG_SNIFF | WINDIVERT_FLAG_RECV_ONLY`
и фильтром `udp and (udp.SrcPort == 5055 or udp.SrcPort == 5056 or
udp.DstPort == 5055 or udp.DstPort == 5056)`. Не задерживает пакеты.
Отдаёт наружу: время, направление, удалённый адрес:порт, полезную нагрузку UDP.
Вызов WinDivert через `golang.org/x/sys/windows` (`LazyDLL`), без CGO.

Интерфейс наружу: `Source` — канал пакетов. Есть вторая реализация —
чтение из файла записи (для тестов и для разбора записей тестера).

### 2. Разбор Photon и событий (internal/photon, internal/game)

Берём разборщик протокола Photon из нашего форка albiondata-client
(MIT). Нужные события: ответ на вход в локацию (Join) с кодом локации,
смена кластера, признаки переподключения к серверу входа.
Точные коды операций/событий берём из форка; если чего-то не хватает,
уточняем по записям тестера.

### 3. Учёт переходов (internal/zones)

Конечный автомат по событиям:
- «ушёл из локации A» — последний пакет со старого игрового сервера /
  запрос смены кластера;
- «пришёл в B» — первый ответ Join с нового сервера;
- время загрузки = разница;
- вылет — нет ответа Join за 30 с или клиент вернулся к серверу входа.

Запись перехода в `переходы.jsonl`:
`{t, from, to, fromName, toName, server, loadSec, ok, fail, strategy}`.
`strategy` — имя включённой стратегии обхода или `off`.

### 4. Обход (internal/bypass)

Запускает `winws.exe` с фильтром только на UDP 5055/5056 и параметрами
выбранной стратегии; останавливает при выключении и всегда при выходе
(в том числе по Ctrl+C и закрытию окна консоли). 6–8 стратегий: UDP-части
стратегий Flowseal (fake-пакеты, повторы, разные TTL/autottl). Список в
`strategies.json`, чтобы тестер мог править без пересборки.

Режим «подобрать»: по очереди включает стратегии, на каждой ждёт 5 переходов,
оценивает (вылеты ×10 + среднее время загрузки), оставляет лучшую.
Можно прервать в любой момент.

### 5. Окно (internal/ui)

HTTP-сервер на `127.0.0.1:<свободный порт>`, страница открывается в браузере
сама. Страница: состояние драйвера и игры, кнопка обхода, выбор стратегии /
«подобрать», последние 30 переходов, таблица «худшие локации» (среднее время,
вылеты) в двух колонках: без обхода / с обходом. Обновляется раз в 2 секунды.
Только русский язык.

### 6. Запись для отладки (internal/record)

Кнопка «Записать 10 минут»: пакеты наблюдателя пишутся в `запись-<время>.azf`
(свой простой формат: время, направление, адрес, нагрузка). Этот файл тестер
присылает, и его можно прогнать через учёт переходов здесь.

## Ошибки

- Нет прав администратора → сообщение + кнопка перезапуска с повышением прав.
- Драйвер не открылся (антивирус, нет файлов) → сообщение, что проверить.
- winws упал → обход помечается выключенным, в окне причина из его вывода.
- Выход программы → winws гасится всегда.

## Проверка

Здесь: `go test` для photon/zones/record на записанных фрагментах;
`GOOS=windows go build` должен собираться; `go vet`.

У тестера, три круга:
1. Наблюдатель: переходы видны, названия локаций правильные.
2. Без обхода: 20+ переходов, есть ли долгие/вылеты, запись для разбора.
3. С обходом («подобрать»): сравнение времени и вылетов.
